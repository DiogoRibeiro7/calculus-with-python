# Capstone Rubric

Each category is scored from 0 to 20 points for a total of 100. Use the guidance below to translate performance into a score band.

## Correctness
- 18-20: Results match the intended mathematics everywhere; error sources are identified and neutralized.
- 14-17: Minor numerical issues exist but the core answers are accurate and explained.
- 9-13: Some significant errors remain; calculations or interpretations partially align with expectations.
- 0-8: Results are broken or unsupported by the provided work.

## Numerical analysis reasoning (step size, convergence)
- 18-20: Step-size strategy and convergence diagnostics are clearly described and directly tied to calculus intuition, with evidence that limits would be approached.
- 14-17: Reasoning covers necessary angles but leaves room for tighter justification or deeper exploration of convergence behavior.
- 9-13: Explanations are surface-level or inconsistent, lacking rigorous connection to step-size or convergence trade-offs.
- 0-8: No meaningful discussion of numerical reasoning is presented.

## Visual quality + interpretation
- 18-20: Plots are well-labeled, purposeful, and interpreted with nuance; visuals reinforce the narrative of the investigation.
- 14-17: Visuals are mostly clear with some interpretive detail but could use better polish or emphasis.
- 9-13: Charts exist but lack clarity, annotations, or connection to the written argument.
- 0-8: Little or no useful visualization is provided.

## Code quality + tests
- 18-20: Code is modular, readable, and leverages repo utilities; accompanying tests/assertions clearly demonstrate correctness boundaries.
- 14-17: Code is generally clean but could reuse abstractions better; some tests exist but are limited.
- 9-13: Code is disorganized or redundant; tests are absent or do not validate core claims.
- 0-8: Code is difficult to follow and untested.

## Clarity of report
- 18-20: The narrative describes goals, steps, and conclusions in logical order with calculus terminology and explicit links to results.
- 14-17: The report is understandable but may skip motivation or leave conclusions implied.
- 9-13: Writing is fragmented; the reader must infer key points or justification.
- 0-8: Report is too vague or missing, making it hard to track the investigation.

Record the score for each category, then sum for a final grade out of 100. Include short comments for the most important strengths or weaknesses.
